
# Luckproof Verdict

내 매매 전략, 운인가 실력인가.

매매 전략을 말로 입력하면 과거 시세로 돌려보고, 그 성과가 **우연과 구별되는지**를 통계로 판정한다.
LLM(ChatKHU)은 전략 문장을 규칙으로 바꾸고 결과를 설명하는 일만 하며, 판정에는 개입하지 않는다.

> 2026 KHU AI Challenge 출품작 · AI 문제해결 솔루션 부문

## 왜 만드나

과거 데이터로 만든 규칙은 당연히 과거에 잘 맞는다. 규칙을 100개 만들면 그중 몇 개는 근거 없이도 우연히 수익이 난다.
수익률 그래프는 실력과 우연을 구별하지 못하고, 개인 투자자는 그 그래프를 믿고 돈을 넣는다.

## 무엇을 따지나

| 검사          | 질문                                                     |
| ------------- | -------------------------------------------------------- |
| 아웃오브샘플  | 전략을 만든 기간이 아닌 다른 기간에서도 통하는가         |
| 거래비용      | 수수료와 세금을 빼고도 남는가                            |
| 벤치마크      | 그냥 시장(지수)이 오른 만큼보다 더 벌었는가              |
| 다중시도 보정 | 여러 번 시도한 끝에 고른 것이라면 그만큼 기준을 올렸는가 |
| 신뢰구간      | 그 성과가 잡음 범위 안인가                               |

출력은 "유효/무효"가 아니라 **이 성과가 우연일 확률**과 그 이유다.

## 구조

```
전략 문장 ──ChatKHU──▶ 규칙(JSON) ──▶ 결정적 엔진 ──▶ 판정 + 근거 ──ChatKHU──▶ 설명문
                                        │
                              일봉 10년 (DuckDB)
```

## 도구 자체의 검증

| 입력                  | 기대 결과                           |
| --------------------- | ----------------------------------- |
| 무작위 규칙 1,000개   | 통과율 5% 미만                      |
| 미래 참조를 심은 전략 | 탐지                                |
| 지수 매수보유 (장기)  | 현금 대비 통과, 지수 대비 구별 불가 |
| 모멘텀 팩터 (장기)    | 통과, 단기로 자르면 미통과          |

## 실행

```bash
pip install -r requirements.txt
python -m luckproof.data.fetch      # 일봉 수집 → data/prices.duckdb
streamlit run app.py
```
