# Luckproof Verdict

내 매매 전략, 운인가 실력인가.

매매 전략을 말로 입력하면 과거 시세로 돌려보고, 그 성과가 **우연과 구별되는지**를 통계로 판정한다.
LLM(ChatKHU)은 전략 문장을 규칙으로 바꾸고 결과를 설명하는 일만 하며, 판정에는 개입하지 않는다.

작품 설명: 주식 투자를 해본 사람은 한 번쯤 내 전략을 상상한다. 하지만 내 돈으로 시장을 시험하기엔 위험하고, 과거 시세로 돌려보는 방법도 함정이 있다. 규칙을 100개 만들면 몇 개는 근거 없이도 우연히 수익이 난다. 수익률 그래프는 실력과 우연을 구별하지 못하고, 투자자는 그 그래프를 믿고 돈을 넣는다. Luckproof Verdict는 전략을 자연어로 입력하면 그 성과가 우연일 확률을 출력한다. “20일 평균선이 60일 평균선을 넘으면 산다”처럼 적으면 ChatKHU가 계산 가능한 규칙으로 바꾸고, 프로그램이 10년치 시세로 따진다. 다른 기간에서도 통하는가, 수수료를 빼고도 남는가, 시장이 오른 만큼보다 더 벌었는가. def build_universe() -> pd.DataFrame:
    krx = fdr.StockListing("KRX")[["Code", "Name", "Market", "Marcap"]]
    top = pd.concat([
        krx[krx.Market == "KOSPI"].nlargest(N_KOSPI, "Marcap"),

def fetch_prices(universe: pd.DataFrame) -> pd.DataFrame:
    frames, failed = [], []
    for i, code in enumerate(universe.code, 1):
        try:
            df = fdr.DataReader(code, START)
        except Exception as e:  # noqa: BLE001
            failed.append((code, repr(e)))
            continue
        if df.empty:
            failed.append((code, "empty"))
            continue
        df = df[["Open", "High", "Low", "Close", "Volume"]].rename(columns=str.lower)
        df.index.name = "date"
        frames.append(df.reset_index().assign(code=code))
        if i % 50 == 0:
            print(f"{i}/{len(universe)}")
        time.sleep(0.2)
    print("failed:", failed)
    return pd.concat(frames, ignore_index=True)

    print(con.execute("SELECT kind, COUNT(DISTINCT code) FROM universe GROUP BY kind").fetchall())

**1. 전략이 훑는 범위** 아닙니다. "요청 시점 기준 KOSPI200"이 아니라 "그 날 기준 KOSPI200"입니다. 둘은 결과가 다릅니다.
