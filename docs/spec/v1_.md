## 데이터 (2단계 확정, 2026-10-12)

- 출처: FinanceDataReader 0.9.202 기본 소스 = 네이버 금융 차트(`fchart.stock.naver.com`). 수정주가(삼성전자 2018-05-04 액면분할 전 가격이 5만 원대로 조정되어 있음을 확인).
- 대상: KOSPI 시가총액 상위 200 + KOSDAQ 시가총액 상위 150 (2026-10-12 기준 현재 상장 종목, 실제 KOSPI200·KOSDAQ150 구성과 다를 수 있음) + ETF 2개(069500 KODEX 200, 229200 KODEX 코스닥150) + 지수 3개(KOSPI, KPI200, KOSDAQ). 지수 구성 종목은 KRX 조회 API가 세션 인증을 요구해 FDR에서 받을 수 없었음.
- 기간: 2016-01-04 ~ 수집일. 거래일 캘린더는 069500(KODEX 200) 기준.
- 저장: `data/prices.duckdb`, 테이블 `prices(code, date, open, high, low, close, volume)`, `universe(code, name, market, kind, as_of)`.
- 데이터 성질(엔진이 지켜야 할 것):
  - `open=0 AND volume=0` 행은 거래정지일. 네이버가 직전 종가를 채워 넣은 것이므로 그 날은 매매 불가로 처리해야 한다.
  - `open>0 AND volume=0` 행도 체결 없음(시가=고가=저가=종가). 매매 불가로 처리.
  - 수정주가 반올림 때문에 종가가 고가·저가 범위를 1원 벗어나는 행이 있다. 오류가 아니므로 무시.
  - 상장폐지 종목 없음(생존 편향 미반영, README 한계에 명시).
- 거래비용 (법령 원문 확인, 2026-10-12):
  - 증권거래세: 유가증권시장 0.05% + 농어촌특별세 0.15% = 매도금액의 0.20%. 코스닥 0.20%(농특세 없음). 근거: 증권거래세법 시행령 제5조(대통령령 제35947호, 시행 2026-01-02), 농어촌특별세법 제5조 제1항 제5호(1만분의 15).
    - 주의: 법제처 API로 받은 시행령 제5조 본문은 "유가증권시장: 영(零)… 2024년까지 1만분의 3"으로 2025년 개정 전 문구였음. 2026년 세율(코스피 0.05%, 코스닥 0.20%)은 2025-12-30 개정 보도(한국세정신문 2025-12 "코스피 0→0.05%, 코스닥 0.15→0.20%")로 확인. 조문 본문 재확인 필요.
  - 위탁수수료: 편도 0.015% 가정(증권사 온라인 기본 수수료. 공식 출처 미확인, 비교 기사 기준). 슬리피지: 편도 0.1% 가정(근거 없음, 3단계에서 민감도 확인).
